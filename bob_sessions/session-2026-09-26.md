## Deployment on Vercel

`.env.local` is **never deployed to Vercel** — it is local-only and gitignored.

### Variables to set in Vercel Dashboard (Settings → Environment Variables)

| Variable | Value | Notes |
|---|---|---|
| `GITHUB_TOKEN` | `ghp_FQneZo…` | GitHub MCP auth — enables REAL GITHUB MCP mode |
| `BOB_API_KEY` | `bob_prod_bob-apikey_…` | Present but currently non-functional for REST inference |
| `WATSONX_MODEL_ID` | `ibm/granite-3-8b-instruct` | Model to use |

### For live AI inference on Vercel (two options)

**Option A — IBM Cloud IAM (recommended, no Bob subscription required if free tier used)**  
Set additionally:
- `WATSONX_API_KEY` = standard IBM Cloud API key (from cloud.ibm.com/iam/apikeys)
- `WATSONX_PROJECT_ID` = watsonx.ai project UUID
- `WATSONX_AI_URL` = `https://us-south.ml.cloud.ibm.com`

**Option B — Fallback text (current default)**  
Without any valid inference key, `explainFinding()` returns `live: false` with a deterministic evidence-bound explanation. The policy engine and all security decisions remain fully functional.
